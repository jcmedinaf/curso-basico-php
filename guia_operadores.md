=====================================================
# GUÍA RÁPIDA DE OPERADORES Y CONCEPTOS EN PHP BÁSICO
=====================================================

# 1. OPERADORES ARITMÉTICOS
-----------------------------------------------------
 +   Suma
 -   Resta
 *   Multiplicación
 /   División
 %   Módulo (Resto de una división entera)
 **  Exponenciación / Potencia

# 2. OPERADORES DE COMPARACIÓN
-----------------------------------------------------
 <   Menor que
 >   Mayor que
 <=  Menor o igual que
 >=  Mayor o igual que
 =   Asignación
 ==  Igualdad de valor (evaluación débil)
 === Igualdad exacta / Identidad (valor y tipo de dato)
 !   Not (Negación lógica)
 !=  Diferente de (evaluación débil)
 !== No idéntico (Diferente en valor o tipo de dato)

# 3. OPERADORES LÓGICOS
-----------------------------------------------------
 &&  AND (Devuelve true si ambas condiciones son verdaderas)
 ||  OR  (Devuelve true si al menos una condición es verdadera)

# 4. CONSIDERACIONES SOBRE DIVISIONES
-----------------------------------------------------
 4 / 2  -> Resultado: 2 (División válida)
 2 / 0  -> Error fatal / Warning (DivisionByZeroError)
